==================================================
Shahnaz & Adhil - Digital Wedding Invitation
==================================================

Overview:
---------
A responsive digital wedding invitation website for Shahnaz & Adhil, 
featuring an interactive hero image slider, countdown timer, event details, 
Google Maps navigation, guestbook wishes section, and background audio.

Project Structure:
------------------
- index.html   : Main structure of the wedding invitation page
- style.css    : Custom styling, layout, typography, and responsive design
- script.js   : Interactive features (slider, countdown timer, audio playback, guest wishes)
- bg1.jpg      : Background image slide 1
- bg2.jpg      : Background image slide 2
- bg3.jpg      : Background image slide 3
- nikkah.mp3   : Background wedding music track

Setup & Installation:
---------------------
1. Ensure all files (index.html, style.css, script.js, bg1.jpg, bg2.jpg, bg3.jpg, nikkah.mp3) 
   are placed in the same root folder.
2. Open 'index.html' in any modern web browser (Chrome, Safari, Edge, Firefox) to view the website locally.
3. For online deployment, host the root folder on GitHub Pages or any static hosting platform.
